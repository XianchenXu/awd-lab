如何获得安全的 GitHub Token？

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Repository access 选 Only select repositories，只选择实验室网站仓库；Repository permissions 把 Contents 设置为 Read and write。建议设置较短有效期，勿发送给任何人。

打开 GitHub Token 创建页面。此编辑器不是 GitHub OAuth 登录，需手动粘贴令牌。

✎ 表单修改会暂存于当前浏览器。连接 GitHub 后点击「直接发布当前栏目」即可在线更新仓库；也保留「下载 .js」作为备份。编辑器页面本身公开可访问，真正的写入权限由 GitHub Token 控制。 不要在公共电脑上使用令牌。

🖼 图片和 PDF 上传到 GitHub

连接后可直接将文件上传到 assets/。完成后复制返回的文件路径，粘贴到栏目图片、头像或讲义链接字段。支持 PNG、JPEG、WebP、GIF、SVG 和 PDF，单文件建议不超过 5 MB。

上传修改后的文件到 GitHub（点击展开）

进入 GitHub 仓库 → 找到 content 文件夹 → 点击 Add file → Upload files → 上传刚刚下载的同名文件 → 提交（Commit changes）。如果提示同名覆盖，确认替换即可。网站一般会在部署完成后更新。基本信息放在仓库根目录的 site.js。
